# ПДД-тренажёр

Личное приложение для подготовки к экзамену по вождению. Код и содержимое здесь **зашифрованы** (AES-256-GCM, ключ — из пароля),
открываются на сайте только после ввода пароля и расшифровываются прямо в браузере.

- **Вход:** страница сайта на GitHub Pages (`index.html`). После входа ключ хранится на устройстве до выхода.
- **Выход:** в приложении — Настройки → «Вход и выход» → «Выйти и стереть»: удаляет с устройства ключ, прогресс, настройки,
  localStorage, IndexedDB, кеши и service worker.
- **Панель хранилища:** [`vault.html`](vault.html) — шифрование и расшифровка в браузере, смена пароля, выход.

## Что здесь лежит

| Путь | Что |
|---|---|
| `index.html`, `login.js`, `gate.css` | Страница входа |
| `sw.js` | Service worker: после входа отдаёт приложение из `vault/`, расшифровывая файлы в памяти |
| `vault-crypto.js` | Общая криптография загрузчика, service worker'а и панели |
| `vault.html`, `vault-panel.js` | Веб-панель хранилища |
| `vault/` | Зашифрованное приложение: `vault.json` (соль и число итераций), `manifest.bin` (оглавление), `x/*.bin` (файлы) |
| `tools/vault.py` | Шифрование и расшифровка из командной строки |
| `tools/serve.py` | Локальный сервер |

Пароля и его хеша в репозитории нет: проверка пароля — это сама расшифровка. Подменить ключ в коде бесполезно —
данные зашифрованы настоящим ключом, а GCM не отдаёт ни байта при неверном.

Порядок работы (расшифровать после clone, зашифровать перед коммитом, две репы) — [docs/VAULT.md](docs/VAULT.md).
